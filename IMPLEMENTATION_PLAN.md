# План реализации совместного просмотра

## Правила выполнения плана

- Реализовывать этапы последовательно, отмечая завершённые пункты через `[x]` только после проверки результата.
- При реализации каждого пункта актуализировать корневой `AGENTS.md`, только если появились полезные долгосрочные сведения: назначение проекта, продуктовые договорённости, архитектурные решения, ответственность важных модулей, ограничения или команды запуска и проверки. Если файла нет — создать его при начале реализации. Не добавлять запись ради самого факта выполнения пункта.
- В `AGENTS.md` хранить краткие актуальные инструкции для дальнейшей работы. Не записывать журнал действий, разовые результаты тестов и диагностики, названия проверенных страниц, ID контекстов, время запуска, переписку и дубли плана. Результаты и незавершённые проверки фиксировать в этом плане. При изменении решения обновлять существующую запись, удаляя устаревшие сведения.
- Если пункт выполнен частично, оставлять `[ ]` и дописывать, что осталось.

## Продуктовые договорённости

- Пользователь выбирает видео на странице; «захват» означает привязку к локальному HTMLVideoElement. Сам медиапоток между участниками не передаётся.
- Trystero обеспечивает комнаты, обнаружение участников и обмен сообщениями.
- Создатель комнаты — постоянный администратор. Только администратор может удалять участников.
- Перезагрузка страницы, перезапуск браузера и временный обрыв связи не завершают комнату. Идентичность создателя сохраняется локально; после восстановления соединения он возвращается администратором. Завершение комнаты — явная команда создателя.
- Все участники, включая администратора, имеют равные права выбирать URL, выбирать видео, управлять просмотром и делиться приглашением.
- Выбранные URL и видео — общее состояние комнаты. Каждый участник воспроизводит соответствующее видео локально.
- Администратор также служит техническим координатором порядка команд и времени; это не даёт ему дополнительных прав управления просмотром.
- Приоритет — максимально одновременный старт и стабильная синхронизация. Наносекундная точность в браузере недостижима: сеть, таймеры и декодирование вносят задержки. Точность измеряется на реальных устройствах; начальный ориентир для испытаний — расхождение до 100–200 мс при нормальных условиях, без обещания такой точности во всех сетях.
